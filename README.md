# Student Marks Analyzer

A Python command-line program that takes student names and marks,
then prints a report with total, average, grade and rank.

## Features
- Input validation (marks must be 0 to 100)
- Total, average and grade calculation
- Rank list (highest to lowest)
- Topper, lowest and class average
- Pass / Fail count

## How to run
1. Install Python 3
2. Download student_analyzer.py
3. Run: python student_analyzer.py

## Built with
Python (lists, dictionaries, functions, loops)
